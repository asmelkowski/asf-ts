# ADR 0001: Use the Google developer documentation style

## Context

The user requested ASD-STE100 or a more suitable standard with an ADR. These documents describe software APIs, data schemas, and implementation plans.

## Decision

Use the [Google developer documentation style](https://developers.google.com/style) for new technical documents. Use short active sentences, precise terms, tables, and diagrams. ADRs contain Context, Decision, and Why. Do not claim certified ASD-STE100 compliance.

## Why

The guide directly addresses software developers and supports code identifiers and API references without a controlled aerospace vocabulary. Its [highlights](https://developers.google.com/style/highlights) provide practical review rules.
